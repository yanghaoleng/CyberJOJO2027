# 相册贴纸透视与镭射反馈

- 共用 `FriendCard` 的详情接入贴纸互动，覆盖收集列表和相册时间线入口。列表缩略图、制作中原图保持轻量显示。
- 轻点/滑动贴纸产生最大 14° 的透视倾斜、沿贴纸透明轮廓裁切的彩虹反光和扫光，四角高光随接触位置增强。弹簧回正；点击后约 1.1 秒退光。
- 手机方向以首次有效读数为中立姿态，横竖屏变化后重新校准；限制旋转幅度，传感器更新合并到动画帧。详情卸载后移除监听，页面隐藏时回正。
- 需要权限的浏览器仅在点击“开启重力感应”后调用权限请求。拒绝、异常或没有传感器时仍可触摸；减少动态效果时保留反光反馈，不做透视与扫光位移。

## 验证

- `node --test src/friends/*.test.js`：12 项通过，覆盖传感器空值、范围、跨角度、横屏轴向和四角映射，以及现有收集存储/对话逻辑。
- `scripts/qa/sticker-foil.mjs`：Chromium 浏览器的真实相册模拟数据，验证四角点按、对应高光、回正、两个相册入口、方向事件、权限同意/拒绝、桌面鼠标与减少动态效果；无页面异常。
- `npm run build` 和 `git diff --check` 通过。
- 方向事件与权限分支使用浏览器模拟；尚未进行实体 iPhone/Android 手机手持验收。
