# 收集可靠性修复（2026-09-16）

## 变更

- 界面统一称为“收集”，照片与贴纸均从左下角相册入口进入。
- 收集先截取原始摄像头画面并写入本机 IndexedDB，再定位目标、制作透明贴纸。画面不含 Rive、字幕或取景框。
- 原图同时进入照片列表与持久化收集任务。识别结果也先保存；后续重试无需再次拍照或重复识别。
- 移除全屏遮罩与右下角假目标框，改为不拦截触摸的轻提示。任意点击、继续对话、Escape、切至后台都会收起前景反馈，不取消原图保存和后台任务。
- 自动重试最多三次，失败仍保留原图，可从详情手动重试；重开页面恢复未完成任务。浏览器关闭或挂起期间不保证执行，回来后继续。
- 完成动画读取真实相册按钮坐标；被打断后不会重新弹出动画或插入语音。
- 新完成贴纸设为未读；默认“全部”视图显示贴纸，进入可视区域播放一次入场动画，随后持久化已读标记。旧收藏不强行变为未读。

## 抠图链路

旧链路在手机端首次从 Hugging Face 加载 BiRefNet fp32（官方列表 973 MB），失败的初始化 Promise 还会被复用。已改为腾讯云预加载 U2Net CPU 推理，手机只上传目标裁剪图。目标可在画面任何位置，英文知识缺失不再使清楚的物品识别失败。

- Node `/api/matting` 网关限制允许的 Origin、图片类型、2 MB 请求体、并发、频率和超时。
- Python 仅监听回环地址 8790，单任务推理；图片仅存在内存，不写文件、不记录图片内容。
- 输入最长边 1280、模型输入 320，保留软边缘并裁去空白。空/全实心遮罩不伪装成功；未生成透明 PNG 时保留原图与待重试状态。
- 处理主线是定位一个物体再抠图；多物体重叠、透明材质、复杂细边仍可能不理想，不承诺百分比成功率或完全精细抠图。

来源：[BiRefNet 模型文件](https://huggingface.co/onnx-community/BiRefNet-ONNX/tree/main/onnx)、[rembg U2Net 前后处理](https://github.com/danielgatis/rembg/blob/main/rembg/sessions/u2net.py)、[U-2-Net 项目](https://github.com/xuebinqin/U-2-Net)。模型 MD5：`60024c5c889badc19c04ad937298a77b`。

## 运维

服务器：现有腾讯云源站。独立 `jocam-matting.service`，与语音隔离，CPUQuota=100%、MemoryMax=900M。

1. 安装 python3-venv；创建 `/opt/jocam-matting/venv`，使用 `deploy/matting-requirements.txt` 安装固定版本依赖。
2. 从 rembg release v0.0.0 获取 u2net.onnx 并核对上述 MD5，保存为 `/opt/jocam-matting/models/u2net.onnx`（不提交大模型至仓库）。
3. 把 `server/matting_worker.py` 放到 `/opt/jocam-matting/releases/<tag>/`，`current` 链接指向该目录，安装此仓库 systemd unit，启动服务。
4. 先检查 `http://127.0.0.1:8790/health`。常规发布脚本会在切换正式前再次检查该 worker，异常时拒绝切换。
5. 前后端仍由原 `install-cyberjojo.sh` 原子切换并保留上一版本，现有测试路由与 Rive 资源不变。worker 更新需独立切换其版本并重启，失败恢复旧 worker 链接。

## 本次验收证据

- 145 项 Node 回归测试通过，覆盖原图优先、失败保留、重试复用识别、取消后恢复、未读兼容、网关 Origin/类型/限流、识别字段。
- 腾讯云实测 rembg 官方 fixtures：植物、车辆、服装人物均返回有透明通道的 PNG，HTTP 200；处理耗时 3.10 / 1.70 / 1.43 秒（仅抠图，不含识别与手机网络）。服务内存约 333 MB，测试峰值约 632 MB。
- 棋盘底人工查看：车辆、人物主轮廓正常；整幅多盆植物有主体选择/半透明问题，裁剪单盆后明显改善，但邻近重叠残留仍可见。不能把 HTTP 200 等同所有画面抠图质量合格。
- iPhone 16 尺寸浏览器，使用固定植物测试摄像头、模拟语音转写/定位响应、真实腾讯云抠图：原图在 processing 阶段已保存；打开相册移除反馈且后台仍完成；失败原图也可查看。
- 成功动画在 90% 进度时中心为 (110, 778.5)，与真实左下入口 (110, 778.5) 对齐，非右下位置。
- 未读进入时 1 个入场动画，已读再次进入时 0 个；无横向溢出。处理中刷新页面后，同一原图自动续作并变为 ready，没有重新弹出前景反馈。
- 修正白描边/阴影的顺序，避免先模糊阴影再染白造成厚重白雾。
- 真实手机麦克风、相机硬件和用户尝试过的具体物体不在上述模拟验收范围；无据声称所有对象成功。
