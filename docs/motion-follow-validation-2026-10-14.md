# 动作跟随验收（2026-10-14）

基于最新远端 `b8b788d` 开发。语音最终识别与文字消息共用关键词解析：叫叫一二三木头人、我做什么你做什么、你跟我学；退出支持结束跟随、不玩了、关闭按钮与 Escape。

- 真正绑定 Rive 的 `bone()`，不是同名图形组。身体、头、左上臂、左前臂、右上臂、右前臂和双腿共 10 根；附加头部 X/Y 节点。前臂带动手掌，不做不存在的独立手指绑定。
- MediaPipe Lite 在经典 Web Worker 内识别，资源随站点托管。确认模块 Worker 与当前 MediaPipe 加载方式不兼容后改为经典 Worker，真实模型成功返回 33 个关键点。
- 队列限制一帧、缩小输入到最长 512 像素、约 15 Hz，暂停后台识别。未检出人体、部位不在画面内或置信度不足时回到自然姿势；模型加载或推理卡住会给出可退出、重试的提示。
- Rive 单独验证抬手/放手：两侧上臂世界方向与目标误差小于 0.04 弧度，退出完整恢复骨骼基准；手臂、头与图形实际变化已截图检查。
- 整页验证三个入口、姿势关键点显示、10 根骨骼、语音/按钮退出、横竖屏和 Domi 切回叫叫进入跟随。暂停 idle 后仍主动驱动重绘；角色切换后重新同步服务端 interaction_mode。
- 语音服务验证 follow 模式仍接收文字/识别输入并暂停自由对话推理，退出后恢复。

复现：`npm test`、`npm run build`；`scripts/qa/motion-follow.mjs` 与 `scripts/qa/motion-rig.mjs` 使用 `PLAYWRIGHT_MODULE` 指定 Playwright，前者可用 `POSE_FIXTURE` 指定测试姿势照片。测试使用官方成人姿势照片和识别文字夹具，不替代孩子在真实手机上连续挥手、遮挡与灯光条件的验收。
