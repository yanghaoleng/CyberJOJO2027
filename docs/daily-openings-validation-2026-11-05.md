# 叫叫随机日常开场验证（2026-11-05）

基于远端 `f0a6de37c41d60bd16573b0de2fa18638f30f0b1` 在独立工作区实施。Mini 原目录和未跟踪的 Rive 临时文件没有被覆盖。原始内部 IP 文档仅用于核对，不进入仓库或静态发布包。

## 行为与保留范围

- 服务端按约 75% 故事、25% 提问选择单条内容，仅该条进入当轮上下文；两个 followups 是候选，单轮最多择一或不用。
- 本机仅保存最多 12 个最近事件编号；不保存新个人画像、时间轨迹或原图。无存储时使用会话内状态。新版本内容库剔除的旧编号被忽略。
- 重连沿用已分享事件，不重播；从未分享开场的孩子主动会话，恢复时不凭空补一条故事。孩子先说话、进入玩法、选择动作跟随或英语练习时让出开场。
- inspect → follow_up、孩子主动指物才展开 explore、feelings 后置、具体反应与最多一问策略保留。真实绘本 → 角色贴纸 → 事件 → 真成语 → 明确自创改词的五次阅读线仍可进入，日常开场不强拉回阅读。
- 分你一口、找一找、玩具朋友名片、心情日记、动作跟随、开口造世界和 Domi 英语、镜头、语音及退出流程沿用已有路径。
- 库 `publishable` 未明确为 `true` 时生产环境不启用素材。显式 `NODE_ENV=test` 可供本地草稿测试。健康接口公开库版本、启用条数、状态与文件 SHA-256，便于核对前后端成套生效。
