# DOMI 本地十关章节

- 原始模型与词汇几何来自同所有者 JMA a14dae2，保留来源与许可；DOMI 身份保持 authored adaptation。
- `/words` 同域独立页面，沿用会话绑定、来源/窗口校验与有界报告协议。家长可通过原语音触发词打开邀请卡片。
- 十关：apple / bread / cake / car / train / airplane / jojo / cat / pig / banana。可自由使用 bike 等额外词。舞台一直保留 DOMI。
- 212 项测试通过。覆盖题干推进、完成封口、非法输入、自主词优先、点词与输入不冒充开口。
- 浏览器在 390px 实际渲染模型和车辆，运行十关并核对同域保存；嵌入退出协议检查 ready/progress/result。
- 正式 ASR WebSocket 连接返回 ready / seeduplex。此检查不代表真实儿童发音或手机麦克风端到端验收。
- CSS 卡片采用透视旋转和淡入；减少动态效果时只淡入。新界面采用 Iconoir SVG 图标。
