# 叫叫咀嚼与比心动效交付规范

## 交付目标

本轮新增两组叫叫角色动画与两组背景道具动画：

| 类型 | 资源名称 | 播放方式 |
| --- | --- | --- |
| 角色 | `Chew_FullBody` | 无缝循环 |
| 角色 | `Reaction_Heart_FullBody` | 一次完整播放 |
| 道具 | `Prop_HeartBalloon_Float_Loop` | 无缝循环 |
| 道具 | `Prop_HeartWreath_Pop` | 一次放大出现、淡出 |

## 现有文件与运行方式

- 叫叫画板已有 `ai叫叫动画状态机`，但主相机当前不播放该状态机；它会直接按时间轴名称播放动作。
- `Reaction_Heart_FullBody` 已在网页中预留。时间轴交付后，比心识别会优先播放它；当前素材不含此时间轴时，网页回退播放 `TalkingEmotion_Happy`。
- `Chew_FullBody` 已保留命名契约；现有喂食仍由程序驱动嘴部与头部，交付该全身时间轴后需要切换播放逻辑。
- 当前人像后方的大爱心由相机合成层绘制。道具 Rive 动画导出后，需要新增独立画板渲染，才能继续保持在孩子人像后方。

## 角色动画制作

### 1. 咀嚼：`Chew_FullBody`

1. 在叫叫画板的动画列表中复制 `TalkingEmotion_Happy`，不要复制 `Talking_Normal`。
2. 重命名为 `Chew_FullBody`。
3. 建议 60fps、1.2–1.6 秒、循环。第 0 帧与末帧必须是同一姿势与数值，便于无缝循环。
4. 保留全身的轻微重心、肩膀和头部节奏；重点补充“嘴里有食物”的脸颊与脸型变化。
5. 交付版本中避免强力关键帧覆盖下列实时控制节点；若确实需要关键帧，需要同步调整网页控制逻辑：

   - `controller_eyeball_location`
   - `controller_faceq`
   - `IP_CJ_mouth_Y`
   - `IP_CJ_mouth1`

### 2. 比心：`Reaction_Heart_FullBody`

1. 复制 `TalkingEmotion_Happy`，重命名为 `Reaction_Heart_FullBody`。
2. 建议 60fps、1.0–1.5 秒、非循环。
3. 第 0 帧保持普通站姿；中段双手在胸前完成爱心；末帧回到能自然衔接普通状态的姿势。
4. 不要使用 `TalkingEmotion_` 前缀。项目会把该前缀的时间轴加入随机表情池；新名称可确保该动作只在识别到比心时触发。

## 道具动画制作

道具不要放入叫叫主画板。请制作独立背景画板，保持透明背景和完整画板尺寸；网页会把该层合成在人像抠图之前。

### 1. 心形气球：`Prop_HeartBalloon_Float_Loop`

- 建议 60fps、2–3 秒、循环。
- 首尾的坐标、缩放、旋转和透明度必须一致。
- 气球位于画面边缘，中央人物区域留空。

### 2. 心形花圈：`Prop_HeartWreath_Pop`

- 建议 60fps、0.6–0.9 秒、非循环。
- 可从 75% 放大至 110%，随后停留或淡出。
- 中心留空，避免覆盖孩子脸部和叫叫。

## 状态机方案

推荐保持当前“直接播放时间轴”方式，**不要修改**原有 `ai叫叫动画状态机`。

如后续明确需要由 Rive 管理反馈状态，请新建 `SM_Feedback`，不要复用旧输入：

```text
Entry → Idle
Any State -- trigger_heart --> Heart →（100% 播完）→ Idle
Idle -- is_chewing=true --> Chew
Chew -- is_chewing=false --> Idle
```

- `trigger_heart`：Trigger；用于一次性进入比心。
- `is_chewing`：Boolean；用于进入／离开循环咀嚼。
- `Heart` 绑定 `Reaction_Heart_FullBody`；离开条件设置为 Exit Time 100%。
- `Chew` 绑定 `Chew_FullBody`；回到 `Idle` 的条件为 `is_chewing = false`。

采用该状态机方案时，网页需改为加载 `SM_Feedback` 并写入上述输入；仅在 Rive 内添加状态机并不会自动接入现有相机。

## 不可改动项与验收

- 不要改动 `Ipad` 时间轴、画板尺寸、画板原点、对象父子层级。
- 不要改动 `Talking_Normal` 第 0 秒和第 0.5 秒的关键姿态，分别用于闭嘴与张嘴采样。
- 导出前逐条播放四组新增动画，检查循环首尾、透明背景、手臂穿插、脸颊变形与结束姿势。
- 导出后替换文件前，检查网页的比心、喂食、语音口型、人脸跟随和切换角色回归。
