## 兼容性与实际差异

五官已恢复，默认、普通表情与出场动作均可正常显示。画板仍为“叫叫”，750×1664，居中原点；四个眼睛、头、嘴部与嘴部定位控制节点均保留。

该文件由旧版 99 条时间轴减少为 47 条，保留 1 个状态机。业务可用的 `TalkingEmotion` 表情由 35 种减少到 18 种，随机播放会使用新文件实际拥有的表情，不等同于旧版全量表情。

| 缺少的原接口 | 本次兼容方式 | 结果 |
| --- | --- | --- |
| `Talking_Normal_close` | 使用 `Talking_Normal` 第 0 秒的闭嘴姿态，张嘴仍采样第 0.5 秒 | 喂食可张嘴、咀嚼和闭嘴复位；未播放说话时间轴 |
| `TalkingEmotion_Expectation` | `TalkingEmotion_Curious` | 进入玩法使用好奇表情 |
| `TalkingEmotion_Frighten` | `TalkingEmotion_Surprised` | 受惊请求使用惊讶表情 |
| `TalkingEmotion_Sure` | `TalkingEmotion_Praise` | OK 回应使用夸赞动作 |

已有原动作的角色仍优先使用原动作。原文件字节未修改；适配仅在应用播放层完成。如要求完全保留旧版表情，仍需由源文件补回缺失时间轴。

| 五官、出场、表情 | 新旧画面并排检查；新文件 18 种业务表情及出场抽帧检查 |
| 眼神与头部跟随 | 上下左右控制后节点坐标与画面均发生对应变化，两种渲染器通过 |

| 页面随机播放 | 观察到动作完成后自动从 Start_Dial 切至 TalkingEmotion_Silent；封面速率 0.25，相机速率 0.8 |

| 自动化回归 | `npm test`：123/123 通过；新增缺失回应与闭嘴采样回归用例 |
